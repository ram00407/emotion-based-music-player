

## 🎶 Emotion-Based Music Player

### 💡 Overview

The Emotion-Based Music Player is an intelligent application that bridges human emotions with music using AI. By analyzing facial expressions through a webcam, the system identifies the user’s current mood and automatically suggests songs that match it. This creates a more immersive and personalized listening experience without requiring manual input.

### 🧠 How It Works

The application uses Computer Vision to detect faces and a Deep Learning model to classify emotions. Once an emotion is recognized, it maps the result to a curated dataset of songs and displays or plays suitable recommendations in real time.

### ✨ Key Highlights

* 📷 Captures live video input via webcam
* 🔍 Detects faces using Haar Cascade Classifier
* 🧠 Classifies emotions using a CNN model
* 🎼 Recommends songs based on detected mood
* ⚙️ Smooth integration with an interactive Streamlit interface
* 🚀 Lightweight and efficient performance

### 🎭 Supported Emotions

* Happy 😊
* Sad 😢
* Angry 😠
* Neutral 😐
* Surprise 😲
* Fear 😨

### 🧰 Technologies Used

* **Python** for development
* **OpenCV** for image processing and face detection
* **TensorFlow/Keras** for building the deep learning model
* **NumPy & Pandas** for data handling
* **Streamlit** for creating the user interface

### 📊 Model Details

* **Architecture:** Convolutional Neural Network (CNN)
* **Dataset:** FER2013
* **Input:** 48×48 grayscale facial images
* **Output:** Emotion classification into 7 categories
